# 반도체 종목 공시 알림 봇

반도체·소부장 약 390개 종목의 **DART 공시를 뜨는 대로** 텔레그램으로 보냅니다.
공시 본문에서 핵심 숫자를 읽어 두세 줄로 요약해 붙이고, 하루 한 번 업황 리포트를 보냅니다.

> 투자 권유가 아닙니다. 공시와 기사를 모아 보여줄 뿐이며, 요약은 자동으로 만든 것이라
> 틀릴 수 있습니다. 판단 전에 반드시 원문을 확인하세요.

## 무엇을 보내나

| 분류 | 내용 |
|---|---|
| 📦 수주 | 단일판매·공급계약 — 계약금액, **최근 매출 대비 %**, 공급 내용, 상대방 |
| ⚠️ 위험신호 | 불성실공시 지정예고, 가압류, 상장폐지 사유 등 |
| 🗣 해명 | 풍문·보도 해명, 조회공시 답변 |
| 🏭 증설·CAPEX | 신규시설투자, 유형자산 취득·양수 — 금액, 자기자본 대비 % |
| 💰 자금조달 | 유상증자(희석률), 전환사채·BW(전환가, 주식 수) |
| 📊 실적 | 영업(잠정)실적 — **예상치 대비**, 최근 5개 분기 추이 |
| 🧿 지분변동 | 5% 대량보유(보고자, 보유비율 변화), 최대주주 변경 |
| 🎤 IR | 기업설명회 개최 일시·목적 |
| 🎁 · 🔀 | 주주환원(배당·자사주), 합병·분할 |
| 📋 지분 공시 | 약식 대량보유·임원 소유상황을 종목명 링크로 묶어서 |
| 📰 주요 기사 | 최근 1시간 이내 기사 중 중요한 것 4건 이내 — **제목 · 내용 · 분석 · 링크** |
| 🌡 데일리 | 평일 18:30 — 종목군 등락, 반도체 수출 지표(한국은행), 오늘의 기사 |

공시는 **종목 하나에 메시지 하나**로 옵니다. 같은 종목의 공시가 여러 건이면 한 메시지에 모읍니다.
서식이 공시마다 달라서, 읽지 못한 공시는 요약 없이 제목과 원문 링크만 나갑니다.

## 시작하기

### 1. 키 준비
- **DART OpenAPI 키** — https://opendart.fss.or.kr (무료)
- **ECOS 키** — https://ecos.bok.or.kr (무료, 업황 지표용)
- **텔레그램 봇** — @BotFather 에서 `/newbot` → 토큰
- **받을 곳**
  - 채널로 보내려면: 채널을 만들고 봇을 **관리자(메시지 게시 권한)** 로 추가한 뒤 `@채널이름`
  - 개인 채팅이면: 봇에게 아무 말이나 보낸 뒤 `python -m bot.whoami` 로 숫자 확인

### 2. GitHub 에서 돌리기
저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 넣습니다.

| 이름 | 값 |
|---|---|
| `DART_API_KEY` | DART 키 |
| `ECOS_API_KEY` | ECOS 키 |
| `TELEGRAM_BOT_TOKEN` | 봇 토큰 |
| `TELEGRAM_CHAT_ID` | `@채널이름` 또는 숫자 |
| `ANTHROPIC_API_KEY` | (선택) 기사 분석용 Claude API 키 |

그다음 **Actions → 반도체 봇 → Run workflow** 에서 `mode` 를 `daily` 로 눌러 메시지가 오는지 확인합니다.
이후는 자동입니다 (평일 06:55 · 12:30 · 18:10 KST 에 이어서 시작).

> **비밀값은 절대 코드나 커밋에 넣지 마세요.** 이 저장소는 공개라 올라간 순간 누구나 봅니다.
> `.env` 는 `.gitignore` 에 들어 있습니다. 실수로 올렸다면 삭제가 아니라 **키를 즉시 재발급**해야 합니다.

### 3. 내 PC·서버에서 돌리기
```bash
pip install -r requirements.txt
cp .env.example .env            # 값을 채운다
python -m bot.watch --dry --days 3     # 보내지 않고 화면에만
python -m bot.watch --loop             # 계속 돌면서 새 공시를 보낸다
python -m bot.daily                    # 데일리 리포트
```
Docker: `docker build -t semi-bot .` 후 `docker run -d --restart unless-stopped --env-file .env -v semi-bot-data:/data semi-bot`

> 서버에서 돌릴 때는 GitHub Actions 예약을 꺼야 합니다. 둘이 각자 기록을 들고 있어 같은 공시가 두 번 갑니다.

## 어떻게 동작하나
- `bot.watch --loop` 는 평일 07:00~20:30(KST)에 **60초마다** DART 공시 목록을 받아 새 것만 걸러 보냅니다.
  종목을 하나씩 조회하지 않고 날짜로 한 번에 받아 호출 수를 줄였습니다 (DART 하루 한도 20,000건).
- 보낸 접수번호는 `bot/state.json` 에 기록하고 5분마다 저장소에 올립니다. 작업이 끊겨도 같은 공시를 다시 보내지 않습니다.
- GitHub 예약 실행은 시작이 늦을 수 있어, 짧게 자주 돌리는 대신 몇 시간짜리 작업을 이어 붙입니다.
- 텔레그램은 채널에 분당 약 20건까지만 받습니다. 한꺼번에 많이 오면 알려준 시간만큼 기다렸다 보냅니다.

## 기사 요약·분석
기사는 한 건에 메시지 한 통으로, 본문을 읽어 **내용**을 뽑아 보냅니다.
**분석**은 `ANTHROPIC_API_KEY` 가 있을 때만 Claude 가 씁니다 (기사에 있는 내용만 근거로 업황·관련 종목에
어떤 의미인지). 키가 없으면 분석 대신 **키워드**와 **관련 종목**만 보여줍니다.
모델이 틀릴 수 있어 분석은 참고용입니다. 기사 본문 일부(3,000자 이내)가 Anthropic API 로 전송됩니다.

## 종목 바꾸기
`bot/universe.json` 의 `rows` 에 `{"ticker": "005930", "name": "삼성전자"}` 형태로 넣거나 뺍니다.

## 파일
```
bot/watch.py      공시·기사 감시 (--loop 가 실시간 모드)
bot/feed.py       DART 공시를 날짜로 받아 대상 종목만 거른다
bot/classify.py   제목으로 분류하고 소음을 거른다
bot/summary.py    공시 원문(본문)에서 항목별 요약
bot/contract.py   수주·IR 본문 해석
bot/earnings.py   잠정실적: 예상치·분기 추이 (네이버 금융)
bot/news.py       기사 수집·중요도 선별
bot/daily.py      데일리 리포트
bot/macro.py      한국은행 반도체 수출 지표
bot/telegram.py   전송 (분할·전송 제한 처리)
bot/gitsync.py    보낸 기록을 저장소에 올린다 (Actions 용)
```

## 주의
- 공시 요약은 서식별 규칙으로 읽습니다. 처음 보는 서식은 못 읽을 수 있습니다.
- 네이버 금융의 비공식 엔드포인트를 씁니다. 예고 없이 바뀔 수 있습니다.
- GitHub Actions 를 오래 도는 작업에 쓰는 것은 약관상 회색지대입니다. 제한되면 서버로 옮기세요.
